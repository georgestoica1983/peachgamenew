# Peach Sensory Symphony 🍑🎶

> A luxury pastel rhythm & touch precision game with 5 escalating stages, procedural Web Audio synthesizer, and an interactive sensory peach featuring the central **Pleasure Spot**.

---

## 🌟 Features
- **The Interactive Sensory Peach:**
  - **Left Cheek (🍓):** Primary tempo and rhythm zone.
  - **Right Cheek (🍑):** Secondary harmony zone.
  - **Pleasure Spot (✨):** Centered right below the stem with a golden radiant aura. Features circular swirl gesture tracking, sustained hold multipliers, and an overheat mechanic.
- **5 Progressive Stages with Rising BPM:**
  1. *Stage 1: First Light (75 BPM)* - Basic approach rings and 2x hold multiplier.
  2. *Stage 2: Velvet Curves (95 BPM)* - Circular swirl gestures and tongue mode.
  3. *Stage 3: Breathless Waves (115 BPM)* - Breath stamina management & overheat protection.
  4. *Stage 4: Poly-Rhythm Desires (130 BPM)* - Multi-touch poly-rhythms across cheeks and Pleasure Spot.
  5. *Stage 5: Grand Climax / KPI Overdrive (145 BPM)* - Rapid climax sprint to 100% KPI.
- **Pure Web Audio Synthesis:** Lo-fi beats, chord pads, shimmer tones, and hit feedback without any external audio files.
- **Mobile-First & Touch-Optimized:** Works seamlessly on mobile browsers (iOS Safari, Android Chrome).
- **Certificate & Digital Signature Pad:** Grade ranking (S/A/B/C) with finger-drawn signature confirmation.

## 🚀 Live Demo on GitHub Pages
To host this automatically on GitHub Pages:
1. Go to your repository on GitHub.
2. Navigate to **Settings** > **Pages**.
3. Under **Source**, select `Deploy from a branch` -> branch `main` -> folder `/ (root)`.
4. Click **Save**. Your game will be live at `https://<your-username>.github.io/<repo-name>/`!
